# ‏PRD-04-DD — فرهنگ داده

> ‏**سطح این زیرسند:** جمع‌بندی **منطقی** داده‌هایی که استوری‌های EP-01 تا EP-07 لازم دارند. فیلدها و مقادیر مجاز اینجا نهایی می‌شوند (Q-27؛ DEC-54). **نوع فنی، کلید، جدول و قالب ذخیره** به طراحی فنی واگذار است `[SRC-02 §7، §13؛ DEC-22]`.
>
> ‏**قاعده:** ستون «منشأ» نشان می‌دهد هر فیلد از کجا آمده است: **BRD** = حداقل فرهنگ داده `[SRC-02 §7]` بدون تغییر · **PRD-03e** = افزوده تأییدشده (CH-07) · **اپیک یا DEC** = فیلدی که یک استوری یا تصمیم تأییدشده PRD-04 لازم داشته است. فیلدهای ستون سوم با هم **تغییر CH-11** را می‌سازند (DEC-121).
>
> ‏**راهنمای برچسب‌ها:** `[SRC-xx §n]` = برگرفته از منبع · **(پیشنهاد)** = پیشنهاد تیم PRD، تأییدشده در چت PRD-04 · ⚠️ = نقطه باز.

### ‏راهنمای شناسه‌ها

| ‏کد | ‏معنی | ‏کجا تعریف شده |
|---|---|---|
| ‏DS-01 … DS-09 | ‏محل ذخیره منطقی داده | ‏PRD-03e §3e.4؛ همین سند |
| ‏VL-NN | ‏فهرست مقادیر مجاز (مثلاً VL-03 = علت‌های ارجاع) **(پیشنهاد — DEC-119)** | ‏همین سند §DD.2 |
| ‏EV | ‏نوع رویداد | ‏PRD-04-EP06 §6.1 |
| ‏US / DEC / CH | ‏استوری / تصمیم / تغییر | ‏زیرسندهای اپیک؛ Master Index |
| ‏RULE / FR / NFR | ‏قاعده داده / نیازمندی عملکردی / نیازمندی کیفی | ‏BRD §5 تا §10 |

> ‏ویژگی‌های ساختاریافته محصول دیگر متن آزاد نیستند: هر ویژگی یک تعریف دارد و مقدار هر محصول با آن سنجیده می‌شود. جست‌وجو، پیشنهاد و جایگزین فقط از ویژگی‌های «قابل جست‌وجو» استفاده می‌کنند.
