# ChatMessage

حباب پیام صفحه گفت‌وگو برای چهار گوینده: مشتری، دستیار، پشتیبان فروشگاه و پیام سیستمی؛ به‌همراه نوار وضعیت.

- **مشتری** (`primary`) در سمت پایان خط (چپ در RTL)؛ **دستیار** (`card` با مرز) و **پشتیبان فروشگاه** (`secondary`، با برچسب «پشتیبان فروشگاه»، بدون نام ادمین — DEC-94) در سمت آغاز.
- پیام سیستمی وسط‌چین و خنثی: «پشتیبان فروشگاه به گفت‌وگو پیوست».
- گزینه‌های رفع ابهام و تأیید حل `ds-chip` هستند (ارتفاع ۴۴px)؛ فقط گزینه‌های **آخرین** پیام فعال‌اند (DEC-133).
- نوار وضعیت S4 با رنگ مالک انسانی (حرکت امضا)؛ S3 با `warning-subtle`.
- زمان تأیید موجودی فقط کنار نتیجه قطعی (DEC-78). متن پیام `body-lg`.
