# ChatMessage

پیام‌های صفحه گفت‌وگو، گروه‌بندی‌شده بر اساس گوینده: مشتری، دستیار، پشتیبان فروشگاه و خط سیستمی؛ به‌همراه نوار وضعیت و پاسخ‌های سریع.

- **ریتم:** ۴px میان حباب‌های یک گوینده، ۲۰px میان گروه‌ها. زمان و نام گوینده **یک بار** زیر هر گروه (`ds-meta`)، بیرون از حباب.
- **مشتری** (`secondary`، رنگ روشن) در سمت پایان خط (چپ در RTL). رنگ برند پررنگ برای پیام‌ها استفاده نمی‌شود تا وزن صفحه روی پاسخ‌ها بماند.
- **دستیار** و **پشتیبان فروشگاه** (`card` با مرز) در سمت آغاز؛ پشتیبان با برچسب «پشتیبان فروشگاه» به رنگ `owner-human` در خط meta، بدون نام ادمین (DEC-94).
- **خط سیستمی** وسط‌چین، بدون حباب: «پشتیبان فروشگاه به گفت‌وگو پیوست».
- **پاسخ سریع** (`ds-chip`) بیرون از حباب، زیر پیام؛ مرز خنثی، فقط hover رنگ برند می‌گیرد. گزینه‌های رفع ابهام در ردیف‌های برچسب‌دار («سایز»، «رنگ»). فقط گزینه‌های آخرین پیام فعال‌اند (DEC-133)؛ گزینه انتخاب‌شده قبلی `ds-chip--on` با تیک. کنش اصلی خطا (`ds-chip--cta`) تنها چیپ پررنگ است.
- **توضیح ثانویه** درون همان حباب با `ds-bub__note` (مثلاً «این به معنای رزرو نیست…»)، نه حباب جدا.
- نوار وضعیت S4 با `owner-human` (حرکت امضا)؛ S3 با `warning-subtle`.
