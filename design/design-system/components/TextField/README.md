# TextField

فیلد متنی با برچسب همیشه‌پیدا، متن کمکی و خطای زیر فیلد.

- برچسب بالای فیلد است؛ placeholder هرگز جای برچسب نیست.
- خطا زیر همان فیلد، با `aria-invalid` و `aria-describedby`، و مشکل و راه رفع را می‌گوید.
- شمارنده نویسه از ۹۰۰ نویسه دیده می‌شود (حد ۱۰۰۰ — A-14؛ DEC-135).
- ورودی عددی با ارقام فارسی و `tabular-nums`.
- مرز فیلد `input` (3.4:1)، فوکوس `ring`. در shadcn: `Input` + `Label`.
