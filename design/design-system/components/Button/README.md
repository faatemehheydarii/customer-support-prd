# Button

دکمه کنش با پنج گونه و سه حالت؛ در هر ناحیه فقط **یک** دکمه `primary`.

- **primary** — کنش اصلی ناحیه: «تحویل‌گرفتن»، «ثبت نتیجه»، «ذخیره».
- **secondary** — کنش پیشنهادی دوم؛ در نمای مالک «درخواست تأیید از مشتری» (DEC-138).
- **outline** — کنش خنثی: «بازگشت»، «لغو».
- **ghost** — کنش درون‌متنی یا کم‌اهمیت.
- **destructive** — کنش برگشت‌ناپذیر یا منفی؛ همیشه با پنجره تأیید.
- **lg** — صفحه گفت‌وگو (هدف لمسی ۴۸px).

حالت‌ها: `disabled` (زمینه `muted`)، `aria-busy="true"` با چرخنده و متن «در حال ثبت…»؛ متن دکمه هنگام کار عوض می‌شود تا موفقیت پیش از ذخیره نشان داده نشود (SP-06). برچسب همیشه فعل کنش است. در shadcn: `Button` با `variant` همنام.
