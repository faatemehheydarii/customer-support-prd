# Sidebar

ریل کناری پنل ادمین و پنل مدیریت فروشگاه: نام محصول و فروشگاه، آیتم‌های منو با شمارنده، و وضعیت پاسخ خودکار.

- زمینه `sidebar` (فیروزه‌ای عمیق) هویت پوسته است؛ سطح کار روشن می‌ماند.
- آیتم فعال: `sidebar-active` + نوار ۳px `sidebar-indicator` در سمت آغاز.
- آیتم‌های بی‌مجوز نمایش داده نمی‌شوند (DEC-126)؛ پنل ادمین و پنل فروشگاه منوی مشترک ندارند.
- کنترل پاسخ خودکار با وضعیت متنی در پوسته پنل ادمین (DEC-136).
- در shadcn: `Sidebar` با متغیرهای `--sidebar-*`.
