# Banner

پیام سطح صفحه برای وضعیتی که روی کار همه اثر دارد؛ با آیکن، عنوان، توضیح و حداکثر یک کنش.

- **warning** — توقف پاسخ خودکار (DEC-136، DEC-143).
- **info** — تنظیمات ناقص: آستانه، مسیر تماس جایگزین.
- **danger** — شکست ثبت (US-04-04)؛ `role="alert"`.
- بنر خط رنگی کناری ندارد؛ کل سطح رنگ می‌گیرد. توضیح با `foreground` روی زمینه روشن.
- بنر بسته‌شدنی نیست وقتی وضعیت هنوز برقرار است. در shadcn: `Alert`.
