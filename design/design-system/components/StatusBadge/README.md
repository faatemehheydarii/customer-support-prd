# StatusBadge

نشان وضعیت مکالمه (S1 تا S6) و نتیجه موجودی، همیشه با برچسب متنی VL-01.

**حرکت امضا:** فقط S4 «در حال رسیدگی» توپر است (`owner-human`) و نام ادمین مالک را کنار وضعیت دارد؛ همه وضعیت‌های دیگر روشن‌اند. این یعنی «این مکالمه مال یک انسان است» (SP-07).

- برچسب‌ها دقیقاً از VL-01 در PRD-04-DD؛ متن تازه ساخته نمی‌شود.
- «ناموجود» خنثی است، نه قرمز: نبودن کالا خطا نیست.
- «نامشخص» هشدار است و هرگز سبز نمی‌شود (SP-04).
- در shadcn: `Badge` با variantهای `s1`…`s6`، `success`، `neutral`، `warning`.
